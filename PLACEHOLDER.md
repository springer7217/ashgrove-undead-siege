https://drive.google.com/file/d/1jvPlwwezDplBA-KufkmoGXODSVcuHPuq/view?usp=drive_link

**To complete the setup:**
1. Download the file from the Drive link above.
2. Rename it to `index.html` (if needed).
3. Commit and push it to the root of this repository.
4. Link the repo to Vercel (static site) for deployment.

Once `index.html` is in the root, the game will be immediately playable and deployable.
