# Ashgrove: Undead Siege

Multiplayer browser-based zombie survival FPS.

## Overview
- Full WebGL rendering with post-processing (SMAA/FXAA)
- Custom weapon systems and unique per-kill visual effects
- Bot AI, team modes, and multiplayer elements
- Maps and arenas
- Polished HUD, menus, and settings

## Important Notice (Anti-Cheat)
The original source includes a strong notice against adding cheats, aimbots, wallhacks, god mode, patchers, or anything that disables anti-cheat, version checks, or related systems. Ordinary improvements are welcome. Cheat tools are not.
